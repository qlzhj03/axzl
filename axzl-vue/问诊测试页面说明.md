# 问诊测试页面使用说明

## 功能介绍

问诊测试页面实现了以下功能：

1. **流式响应**：对接后端SSE接口，实现实时数据流传输
2. **打字机效果**：AI助手的回复逐字显示，提供流畅的用户体验
3. **Markdown渲染**：支持完整的Markdown格式（标题、列表、代码块、表格等）
4. **快速问题**：提供常用问题模板，方便用户快速体验

## 安装依赖

为了获得更好的Markdown渲染效果，建议安装`marked`库：

```bash
cd axzl-vue
npm install marked
```

安装完成后，页面会自动检测到marked库并使用完整的Markdown解析功能。

## 页面访问

启动项目后，访问以下路径：
```
http://localhost:80/consultation-test
```

或在系统菜单中点击"问诊测试"导航项。

## 使用方法

1. 在输入框中输入症状描述，例如："我最近头痛、发烧"
2. 或者点击快速问题标签选择一个预设问题
3. 按Ctrl+Enter或点击"发送"按钮
4. 观察AI助手的流式回复，体验打字机效果
5. 回复内容会自动滚动到底部

## 技术实现

- **前端框架**：Vue 3 + TypeScript
- **UI组件**：Element Plus
- **流式通信**：Server-Sent Events (SSE)
- **Markdown解析**：marked库（自动检测，可选）

### 核心特性

1. **动态导入**：页面会尝试动态导入marked库，如果未安装则使用基础Markdown解析
2. **错误处理**：完善的错误处理机制，确保页面稳定性
3. **响应式设计**：适配不同屏幕尺寸
4. **用户体验**：加载状态、禁用状态、自动滚动等细节优化

## Markdown支持

### 基础格式（始终支持）
- **粗体**：`**文本**`
- *斜体*：`*文本*`
- `代码`：`` `代码` ``
- 换行：自动转换

### 完整格式（安装marked后支持）
- 标题：`# H1`, `## H2`, `### H3`等
- 列表：无序列表 `- item`，有序列表 `1. item`
- 代码块：``` ```language\ncode\n``` ```
- 引用：`> 引用文本`
- 表格：`| Header | Header |\n| ------ | ------ |\n| Cell | Cell |`
- 链接：`[文本](URL)`
- 图片：`![alt](URL)`

## 注意事项

1. 确保后端服务正常运行
2. 用户需要登录才能使用问诊功能
3. 流式响应超时时间设置为5分钟
4. 网络不稳定时可能出现连接中断
5. 建议在Chrome、Firefox等现代浏览器中使用

## 故障排除

### 问题1：页面无法加载
- 检查路由配置是否正确
- 确认组件文件路径正确
- 查看浏览器控制台错误信息

### 问题2：流式响应不工作
- 检查后端服务是否启动
- 确认API接口地址正确
- 查看网络连接和认证token

### 问题3：Markdown渲染异常
- 检查marked库是否正确安装
- 查看浏览器控制台是否有相关错误
- 尝试刷新页面重新加载
