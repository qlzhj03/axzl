# 安心诊聊平台（AXZL）测试报告

## 1 引言

### 1.1 编写目的

本文档是安心诊聊平台（AXZL）的系统测试报告，记录各功能模块的测试用例和测试结果，验证系统是否满足需求规格说明书中的各项需求。

### 1.2 测试范围

| 测试类型 | 范围 |
|---------|------|
| 功能测试 | 用户认证、智能问诊、知识库管理、健康档案、AI模型管理、用药提醒、系统监控 |
| 安全测试 | JWT认证、权限控制、密码安全、XSS防护 |
| 兼容性测试 | 主流浏览器兼容性 |

### 1.3 测试环境

| 项目 | 配置 |
|------|------|
| 操作系统 | Windows 10 IoT Enterprise LTSC 2021 |
| JDK | Java 21 (OpenJDK) |
| 数据库 | MySQL 8.0.33 (Docker) |
| 缓存 | Redis 7.x (Docker) |
| 向量库 | Milvus 2.x standalone (Docker) |
| 嵌入模型 | BGE-large-zh-v1.5 (localhost:8718) |
| 大语言模型 | DeepSeek V4-Flash (api.deepseek.com) |
| 浏览器 | Chrome 126, Firefox 128, Edge 126 |

### 1.4 测试数据

系统初始化脚本`sql/init.sql`提供了：5个角色、20个测试用户（密码`admin123`）、10条健康档案、3个问诊会话、6个AI模型配置、完整RBAC权限分配。
