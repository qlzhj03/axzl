# 安心诊聊平台（AXZL）测试报告

## 1 引言

### 1.1 编写目的

本文档是安心诊聊平台（AXZL）的系统测试报告，记录系统各功能模块的测试用例设计、执行过程和测试结果，验证系统是否满足需求规格说明书中定义的功能需求和非功能需求。

### 1.2 测试范围

| 测试类型 | 范围 |
|---------|------|
| 功能测试 | 用户认证、智能问诊、知识库管理、健康档案、健康知识学习、AI模型管理、系统监控 |
| 接口测试 | 所有RESTful API接口 |
| 安全测试 | JWT认证、权限控制、密码安全、XSS防护 |
| 性能测试 | API响应时间、并发处理能力 |
| 兼容性测试 | 主流浏览器兼容性 |

### 1.3 测试环境

| 项目 | 配置 |
|------|------|
| 操作系统 | Windows 10 IoT Enterprise LTSC 2021 |
| JDK | Java 21 (OpenJDK) |
| 数据库 | MySQL 8.0.33 (Docker) |
| 缓存 | Redis 7.x (Docker) |
| 向量库 | Milvus 2.x standalone (Docker) |
| 嵌入模型 | BGE-large-zh-v1.5 (localhost:8718) |
| 大语言模型 | DeepSeek V4-Flash (api.deepseek.com) |
| 浏览器 | Chrome 126, Firefox 128, Edge 126 |
| 构建工具 | Maven 3.9.x, Node.js 20.x |

### 1.4 测试数据

系统初始化脚本`sql/init.sql`提供了完整的测试数据：
- 5个角色（超级管理员、医疗专家、普通医生、护士助理、患者）
- 20个测试用户（密码统一为`admin123`）
- 10条健康档案记录
- 3个问诊会话（含11条对话消息）
- 6个AI模型配置
- 11篇健康知识文章（含分类和互动数据）
- 完整的RBAC权限分配
