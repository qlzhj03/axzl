# 安心诊聊平台（AXZL）用户操作手册

## 1 引言

### 1.1 编写目的

本手册旨在指导用户正确使用安心诊聊平台（AXZL）的各项功能，包括系统登录、智能问诊、健康知识学习、健康档案管理等。本手册适用于所有系统用户，包括管理员、医疗专家、医生、护士助理和患者。

### 1.2 系统简介

安心诊聊平台是一个基于人工智能技术的医疗健康服务平台，主要提供以下功能：

- **智能问诊**：基于AI大语言模型，结合医学知识库和个人健康档案，提供专业的健康咨询服务
- **健康知识学习**：提供分类管理的健康科普文章，帮助用户提升健康素养
- **健康档案管理**：为用户建立个人健康档案，记录健康信息
- **知识库管理**（管理员）：管理医学知识库，支持文档上传和向量化
- **系统管理**（管理员）：用户、角色、菜单、字典等系统配置管理

### 1.3 角色说明

| 角色 | 说明 | 主要功能 |
|------|------|---------|
| 超级管理员 | 系统最高权限 | 所有功能 |
| 医疗专家 | 医学专业人士 | 知识库管理、问诊管理、文章发布 |
| 普通医生 | 临床医生 | 智能问诊、健康档案管理 |
| 护士助理 | 医疗辅助人员 | 查看问诊记录、查询档案 |
| 患者 | 普通用户 | 智能问诊、健康知识学习、个人档案 |

### 1.4 访问地址

- 管理端：`https://localhost` 或 `https://服务器IP`
- 患者端：通过管理端导航或直接访问患者端路径

### 1.5 浏览器要求

推荐使用以下浏览器的最新版本：
- Google Chrome
- Microsoft Edge
- Mozilla Firefox

## 2 系统登录

### 2.1 登录操作

**操作步骤：**

1. 打开浏览器，输入系统地址，进入登录页面
2. 在"用户名"输入框中输入您的账号
3. 在"密码"输入框中输入您的密码
4. 如系统开启了验证码功能，在"验证码"输入框中输入图片上显示的字符
5. 点击"登录"按钮

**默认测试账号：**

| 角色 | 用户名 | 密码 |
|------|--------|------|
| 超级管理员 | admin | admin123 |
| 医疗专家 | expert_zhang | admin123 |
| 普通医生 | doctor_chen | admin123 |
| 护士助理 | nurse_wu | admin123 |
| 患者 | patient_huang | admin123 |

**注意事项：**
- 连续输入错误密码5次，账户将被锁定10分钟
- 登录成功后，系统会自动跳转到对应角色的首页

### 2.2 用户注册

**操作步骤：**

1. 在登录页面，点击"注册"链接
2. 填写用户名、密码、确认密码
3. 点击"注册"按钮
4. 注册成功后，自动跳转到登录页面

**注意事项：**
- 用户名不能与已有用户重复
- 新注册用户默认为"患者"角色
- 注册功能可由管理员在系统参数中关闭

### 2.3 退出登录

**操作步骤：**

1. 点击页面右上角的用户头像
2. 在下拉菜单中选择"退出登录"
3. 系统清除登录状态，跳转到登录页面

## 3 患者端功能

### 3.1 患者首页

登录后，患者角色的用户将看到患者端首页，包含以下内容：

- **快速入口**：智能问诊、健康档案、健康知识、我的文档
- **最近问诊**：显示最近的问诊会话
- **推荐文章**：推荐阅读的健康知识文章

### 3.2 智能问诊

智能问诊是本系统的核心功能，用户可以通过自然语言描述症状，获取AI健康咨询建议。

#### 3.2.1 新建问诊

**操作步骤：**

1. 点击底部导航栏的"智能问诊"或首页的"开始问诊"按钮
2. 在输入框中描述您的症状或健康问题
3. 点击发送按钮或按回车键发送消息
4. AI将实时流式回复健康建议

**示例输入：**
- "我最近三天流鼻涕、嗓子疼，今天开始干咳，没有发烧"
- "上腹部隐痛一周，餐后加重，伴反酸嗳气"
- "高血压5年了，目前吃硝苯地平控释片，血压还是偏高怎么办"

**注意事项：**
- 尽量详细描述症状，包括：症状部位、持续时间、伴随症状、既往病史等
- AI回复仅供参考，不替代专业医生诊断
- 如有紧急情况，请立即拨打120或前往医院就诊

#### 3.2.2 知识库检索

在问诊输入框旁边有一个"知识库检索"开关：

- **开启**（默认）：AI会结合医学知识库中的内容进行回复，回复更加专业和有据可依
- **关闭**：AI仅基于通用知识和对话历史进行回复

#### 3.2.3 会话管理

**查看历史会话：**
1. 点击问诊页面左侧的会话列表
2. 可以看到所有历史问诊会话，按时间排序
3. 置顶的会话显示在最上方

**会话操作：**
- **重命名**：点击会话右侧的"..."菜单，选择"重命名"，输入新标题
- **置顶/取消置顶**：点击会话右侧的"..."菜单，选择"置顶"
- **删除**：点击会话右侧的"..."菜单，选择"删除"

**满意度评价：**
1. 在会话详情页面，找到满意度评分区域
2. 点击1-5星进行评分
3. 评分后不可修改

### 3.3 健康知识学习

#### 3.3.1 浏览文章

**操作步骤：**

1. 点击底部导航栏的"健康知识"
2. 可以看到健康知识文章列表
3. 使用顶部的分类标签筛选文章
4. 点击文章卡片进入文章详情

**文章分类：**
- 常见疾病（呼吸系统、心血管系统、消化系统）
- 健康生活（饮食营养、运动健身、睡眠健康）
- 心理健康
- 母婴健康
- 中医养生

#### 3.3.2 文章阅读

在文章详情页面，您可以：

- **阅读全文**：系统会自动记录您的阅读进度
- **点赞**：点击文章底部的"点赞"按钮
- **收藏**：点击文章底部的"收藏"按钮
- **查看AI摘要**：部分文章提供AI生成的摘要，可快速了解文章要点

#### 3.3.3 我的收藏

**操作步骤：**

1. 点击底部导航栏的"健康知识"
2. 点击"我的收藏"标签
3. 查看所有收藏的文章列表
4. 可以取消收藏

#### 3.3.4 学习统计

在"我的收藏"页面，可以查看学习统计信息：
- 阅读文章数
- 累计阅读时长
- 收藏文章数
- 点赞文章数

### 3.4 健康档案

#### 3.4.1 查看我的档案

**操作步骤：**

1. 点击底部导航栏的"健康档案"
2. 系统显示您的个人健康档案信息
3. 首次访问时，系统会自动创建空档案

**档案包含信息：**
- 基本信息：出生日期、性别、血型、身高、体重
- 健康史：过敏史、既往病史、家族病史
- 生活习惯

#### 3.4.2 编辑档案

**操作步骤：**

1. 在健康档案页面，点击"编辑"按钮
2. 修改需要更新的信息
3. 点击"保存"按钮

**注意事项：**
- 健康档案信息会在智能问诊时自动注入AI对话上下文
- 准确的健康档案有助于AI提供更加个性化的健康建议
- 过敏史信息尤为重要，请务必准确填写

### 3.5 我的文档

#### 3.5.1 上传文档

**操作步骤：**

1. 点击底部导航栏的"我的文档"（如有权限）
2. 点击"上传文档"按钮
3. 选择要上传的文件（支持txt、Word、PDF、Markdown格式）
4. 等待上传完成

**注意事项：**
- 单个文件大小限制为10MB
- 上传后系统会自动进行文本提取和向量化处理
- 处理完成后，文档内容将可用于智能问诊的知识库检索

#### 3.5.2 文档管理

在文档列表中，您可以：
- 查看文档处理状态（处理中/已完成/失败）
- 查看文档分块数
- 删除文档
- 对处理失败的文档执行"重新处理"

### 3.6 个人信息

**操作步骤：**

1. 点击底部导航栏的"我的"
2. 可以查看和修改个人信息
3. 支持修改：昵称、邮箱、手机号、性别、头像
4. 支持修改密码（需要输入旧密码）

## 4 管理端功能

### 4.1 管理端首页（Dashboard）

管理端首页显示系统概览信息：

- 今日登录数
- 今日问诊数
- 快捷功能入口

### 4.2 业务管理

#### 4.2.1 知识库管理

**适用角色：** 超级管理员、医疗专家

**查看知识条目：**
1. 点击左侧菜单"业务管理" → "知识库管理"
2. 查看知识条目列表，支持按标签、状态筛选
3. 点击条目查看详情

**新增知识条目：**
1. 点击"新增"按钮
2. 填写：问题、答案、分类标签、评分、关联疾病
3. 点击"确定"保存

**导入向量：**
1. 选择"未导入"状态的条目
2. 点击"导入向量"按钮
3. 系统将文本向量化后存入Milvus向量库
4. 支持单条导入和批量导入

#### 4.2.2 文档管理

**适用角色：** 超级管理员、医疗专家

**上传文档：**
1. 点击左侧菜单"业务管理" → "文档管理"
2. 点击"上传文档"按钮
3. 选择文件并上传
4. 系统自动进行异步向量化处理

**文档处理状态：**
- 未处理（灰色）：刚上传，等待处理
- 处理中（蓝色）：正在进行文本提取和向量化
- 已完成（绿色）：处理成功，可用于知识库检索
- 失败（红色）：处理失败，可点击"重新处理"

#### 4.2.3 问诊记录管理

**适用角色：** 超级管理员、医疗专家

**查看问诊记录：**
1. 点击左侧菜单"业务管理" → "问诊记录"
2. 查看所有用户的问诊会话列表
3. 点击会话查看详细对话记录

**操作功能：**
- 查看会话详情（含完整对话记录）
- 删除会话
- 批量删除

#### 4.2.4 健康档案管理

**适用角色：** 超级管理员、医疗专家、普通医生

**查看档案列表：**
1. 点击左侧菜单"业务管理" → "健康档案管理"
2. 查看所有用户的健康档案列表

**Excel导入导出：**
1. **导出**：点击"导出"按钮，系统生成Excel文件并下载
2. **下载模板**：点击"导入" → "下载模板"，获取Excel导入模板
3. **导入**：点击"导入"按钮，选择填写好的Excel文件上传

#### 4.2.5 健康知识文章管理

**适用角色：** 超级管理员、医疗专家

**文章管理：**
1. 点击左侧菜单"业务管理" → "健康知识学习" → "文章管理"
2. 查看文章列表，支持按分类、状态筛选

**新增文章：**
1. 点击"新增"按钮
2. 填写：标题、分类、摘要、内容（富文本编辑器）、封面图片、作者、来源、标签
3. 选择状态：草稿或直接发布
4. 点击"确定"保存

**发布/下架文章：**
1. 在文章列表中，点击文章右侧的"发布"或"下架"按钮
2. 发布后患者端可见，下架后患者端不可见

**AI生成摘要：**
1. 选择一篇文章
2. 点击"AI摘要"按钮
3. 系统自动调用AI生成文章摘要

**分类管理：**
1. 点击左侧菜单"业务管理" → "健康知识学习" → "分类管理"
2. 支持新增、编辑、删除分类
3. 支持两级树形分类结构

#### 4.2.6 AI模型管理

**适用角色：** 超级管理员

**查看模型列表：**
1. 点击左侧菜单"系统工具" → "AI模型管理"
2. 查看所有AI模型配置

**切换默认模型：**
1. 找到要设为默认的模型
2. 点击"设为默认"按钮
3. 系统立即切换，无需重启

**新增模型配置：**
1. 点击"新增"按钮
2. 填写：提供商标识、模型名称、API地址、API密钥、模型类型、参数配置
3. 点击"确定"保存

**模型类型说明：**
- text：文本对话模型（用于智能问诊）
- embedding：向量化模型（用于知识库嵌入）
- image：图像模型
- audio：音频模型

## 5 常见问题解答

### 5.1 登录问题

**Q：忘记密码怎么办？**
A：请联系系统管理员重置密码。管理员可以在"用户管理"中点击"重置密码"，将密码重置为默认值`123456`。

**Q：账户被锁定了怎么办？**
A：连续输入错误密码5次后账户会被锁定10分钟。请等待10分钟后重试，或联系管理员在"登录日志"中执行"解锁"操作。

**Q：登录后看不到某些菜单？**
A：不同角色有不同的菜单权限。如果您需要更多权限，请联系管理员分配相应的角色。

### 5.2 智能问诊问题

**Q：AI回复的内容准确吗？**
A：AI回复基于医学知识库和大语言模型生成，仅供参考。如有健康问题，请以专业医生的诊断为准。系统在显著位置标注了"AI辅助问诊，不替代医生诊断"的提示。

**Q：问诊时AI回复很慢怎么办？**
A：AI回复速度受网络状况和AI服务负载影响。通常首字响应在1-3秒内。如果持续较慢，请检查网络连接或稍后重试。

**Q：如何让AI给出更准确的回复？**
A：建议：1）详细描述症状，包括部位、时间、程度等；2）完善个人健康档案，AI会参考您的个人情况；3）开启知识库检索功能。

**Q：对话记录会被其他人看到吗？**
A：普通用户只能查看自己的对话记录。管理员可以查看所有用户的记录（用于系统管理目的）。系统严格保护用户隐私。

### 5.3 健康知识学习问题

**Q：文章内容可靠吗？**
A：文章由医疗专家编写和审核，内容来源可靠。但健康知识仅供参考，具体诊疗请咨询医生。

**Q：阅读进度是如何记录的？**
A：系统通过页面滚动位置自动记录阅读进度。当您退出文章后重新进入，可以从上次阅读的位置继续。

### 5.4 健康档案问题

**Q：健康档案信息会被用在哪里？**
A：健康档案主要在智能问诊时自动注入AI对话上下文，帮助AI提供更加个性化的健康建议。过敏史、既往病史等信息对AI的回复质量有重要影响。

**Q：如何确保健康档案的准确性？**
A：请根据真实的健康状况填写档案信息。如有不确定的信息，可咨询医生后填写。档案信息可随时修改更新。

### 5.5 文档管理问题

**Q：上传文档后多久可以用于问诊？**
A：文档上传后会自动进行异步向量化处理。处理时间取决于文档大小，通常几秒到几分钟不等。您可以在文档列表中查看处理状态。

**Q：文档处理失败了怎么办？**
A：点击文档右侧的"重新处理"按钮即可重新进行向量化处理。如果多次失败，请检查文档格式是否受支持，或联系管理员。
